# Research Project Template

A starting point for organizing a reproducible research project. Replace this
text with the project question, team, and study-specific details.

## Project structure

| Path | Contents |
| --- | --- |
| `data/raw/` | Original, unmodified data collected for the project |
| `data/processed/` | Cleaned or transformed data produced by analysis |
| `data/external/` | Third-party data, with its source and license documented |
| `scripts/` | Reusable code for cleaning, analysis, and generating outputs |
| `notebooks/` | Exploratory work; move stable analyses into scripts |
| `articles/` | Key papers and a bibliography or notes (respect copyright) |
| `reports/` | Drafts and final written reports |
| `results/figures/` | Figures generated by analysis |
| `results/tables/` | Tables generated by analysis |
| `docs/` | Study protocol, data dictionary, and project-specific documentation |

## Suggested workflow

1. Document the research question, sources, and methods in `docs/`.
2. Keep source data unchanged in `data/raw/`; record provenance and any access
   restrictions. Do not commit sensitive or restricted data.
3. Use scripts in `scripts/` to transform data and run analyses. Save derived
   data in `data/processed/` and generated figures and tables in `results/`.
4. Record article citations and links in `articles/`; only store full-text
   copies when their license permits it.
5. Write up methods and findings in `reports/`, noting how to reproduce results.

Use relative paths from the project root, and document software requirements
and commands needed to reproduce the analysis as the project develops.
